# Project Agent Rules — Social Media Application

## Redux Toolkit Teaching Rule

When explaining, teaching, or demonstrating anything related to Redux, Redux Toolkit,
RTK Query, state management, reducers, actions, dispatch, selectors, cache, mutations,
optimistic updates, or authentication flow with Redux:

1. **Always use the actual project files** in `ui/src/redux/`. Never use generic
   Todo app examples or invented code that doesn't exist in this project.

2. **Always follow the mentor teaching style**:
   - Explain the concept first (plain English, with analogies)
   - Explain why we need it (what problem it solves)
   - Show the exact project code (use `view_file` to read fresh content)
   - Explain every line of that code
   - Explain what happens internally inside Redux Toolkit
   - Show the next connected file in the chain
   - Ask quiz questions before moving on

3. **Never assume prior Redux knowledge.** The user is a beginner. Treat every
   Redux explanation as if it's their first time hearing the concept.

4. **The 18-part curriculum** defined in the `redux-toolkit-mentor` skill is the
   canonical teaching structure. Follow it in order for any full Redux lesson.

5. **Read files fresh before quoting.** Project files evolve. Always use `view_file`
   rather than relying on memory when showing code to teach from.
